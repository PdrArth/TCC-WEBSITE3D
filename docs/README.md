# Documentação

Os documentos foram separados por assunto para facilitar a consulta sem misturar registros históricos, recursos visuais e créditos.

| Pasta | Conteúdo |
| --- | --- |
| [`assets/`](assets/README.md) | Capturas da experiência e evidências visuais versionadas. |
| [`audio/`](audio/README.md) | Histórico técnico das mudanças de áudio. |
| [`credits/`](credits/README.md) | Autoria, licenças e proveniência de recursos de terceiros. |
| [`design/`](design/README.md) | Decisões de interface e referências visuais arquivadas. |
| [`research/`](research/README.md) | Organização editorial e registros de leitura. |
| [`validation/`](validation/README.md) | Relatórios de verificação por versão. |

Os arquivos por versão documentam decisões e verificações feitas durante a construção do site. Eles não substituem o TCC nem devem ser lidos como resultados de um novo experimento.

Para entender como o código, a cena 3D, os recursos públicos e os testes se conectam, consulte [`architecture.md`](architecture.md).
