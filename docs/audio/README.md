# Registros de áudio

Os arquivos desta pasta guardam o histórico técnico das mudanças de áudio da experiência, organizadas pela versão em que foram verificadas. São registros de implementação e teste; a proveniência e as condições de uso de cada recurso ficam em [`../credits/assets.md`](../credits/assets.md).

Os relatórios não significam que todos os recursos descritos estejam ativos na versão atual. Consulte a validação mais recente para entender o estado de cada mudança.
