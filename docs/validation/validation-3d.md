# Entrega do mundo 3D

Implementação em G:\site-tcc: quatro pavilhões, personagem com espera/caminhada, leitura compartilhada, 24 referências e PDF acadêmico preservado.

| Verificação | Resultado |
|---|---|
| Principal / leve / avatar | 4.854.116 / 2.110.920 / 301.648 bytes, abaixo dos orçamentos |
| Modelagem / poster | Blender 4.5.14 LTS, fontes e scripts; poster 1600 × 1200, 173.414 bytes |
| Grafo | 31 nós, 33 arestas; quatro entradas e alturas de escada |
| Navegação | Percursos, troca de destino, cancelamento, chegada e retorno |
| Acessibilidade | Teclado, foco/trap, movimento reduzido, leitura, controles móveis de 44 px |
| Áudio | Clique obrigatório, volumes baixos ajustáveis, silenciamento, créditos |
| Falhas | WebGL perdido, modelo ausente, novidades indisponíveis e carregamento lento preservam acesso |
| Editorial | 11 centrais + 13 complementares; arquivos acadêmicos preservados |
| Privacidade | Somente novidades publicadas; revisão/MCP exigem proprietário |
| Testes | 16 Node + 15 verificações editoriais em D1 isolado; TypeScript/lint aprovados |

A sessão apresentou amostras de 83–116 FPS e uma fase próxima de 1 FPS no navegador interno enquanto o chat não estava visível. A qualidade se adapta; lentidão persistente usa o poster e oferece nova tentativa em Créditos. A caminhada mantém seu tempo. Esses dados não garantem desempenho em aparelhos não testados.
