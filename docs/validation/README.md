# Validações

Os relatórios registram verificações da experiência por versão. A [validação v20](validation-v20.md) é o registro mais recente desta pasta; os documentos anteriores permanecem como histórico de decisões e regressões corrigidas.

As verificações foram feitas em navegador e, quando indicado, em emulação móvel. Cada relatório delimita o que foi testado; eles não comprovam desempenho em todos os aparelhos nem substituem testes físicos.
